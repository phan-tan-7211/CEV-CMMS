# Equipment Status Settings quick verification

1. Open Settings > Trạng thái thiết bị.
2. Confirm the Add Status button is above the table and never overlays Edit/Delete icons.
3. Create a temporary status.
4. Edit its name/color.
5. Delete it and confirm the in-app destructive modal appears on Expo Web and native.
6. After confirmation, the row must disappear after the master list reloads.
7. Locked rows must show only the lock icon and expose no Edit/Delete actions.
